# 초기 마스터 데이터

원본: `차단기 트립 이력.xlsx`, SHA-256 `04b7bd525bde8f764498693b2e786fd0cde412ba5f14b649c0f0d6fb848988a0`.

사용자 확정에 따라 **분전함마스터와 차단기마스터 두 시트만 사용한다.** 1관·2관·3관·4관·기타의 과거 트립과 사용법 시트는 변환 자료·앱에서 제외했다. 과거 이력 연결 규칙과 확인 대기 기능은 필요 없다.

## 초기 데이터

| 대상 | 적재 수량 | 처리 |
| --- | ---: | --- |
| 분전함 | 164개 | 원본 165행 중 같은 4관/B2/D-LE-B2 두 행을 합침. 위치 `4관 EPS` 유지 |
| 차단기 | 171개 | 원본 258행에서 SPARE 87개 제외. 차단기번호가 있는 행만 사용. 번호 없이 분전함만 나열한 행은 차단기로 생성하지 않음 |
| 설치 구간 | 171개 | 차단기마다 최초 구간 생성. 설치일 미상 12개 |
| 트립 이력 | 0개 | 과거 이력 시트 전체 제외 |

## 확정된 변환

- 관 `12 → 2관`, `34 → 3관`. 공용 관을 새로 만들지 않는다.
- A-LE-B2 / E1~E10의 PORT수 `20`은 `2P`로 정정한다. PORT·정격전류의 P/A 단위는 숫자와 분리한다.
- SPARE 및 SPARE(증설) 87개는 초기 등록에서 제외한다. 구 버전의 초기 SPARE와 대조할 원문은 `excludedSpareBreakers`에 보존하며 실제 사용 시 새 차단기로 등록한다.
- 원본의 빈 값은 빈 문자열 또는 null로 보존한다. 위치·부하·종류·트립사유를 추정하지 않는다.
- 특기사항은 원문을 유지하며 FROM분전함 8행은 `FROM분전함: 값` 형태로 분전함 특기사항에 함께 보존한다.
- 차단기마스터의 비어 있는 분전함번호는 같은 목록의 직전 분전함번호를 이어 사용한다. 분전함마스터의 번호와 정확히 연결한다.
- 1관 12·13층 지원은 사용자 확인대로 유지한다. 제외한 이력 시트에서 해당 층의 설비를 새로 만들지는 않는다.

## 앱 적용

Room v3의 `initial_data_import`에 `excel-masters-v1` 적용 완료를 저장한다. DB를 처음 열 때 마스터·최초 구간·적용 기록을 한 트랜잭션으로 저장한다. 기존 DB도 v1→v2→v3 또는 v2→v3 업그레이드 후 동일하게 적용한다.

기존 동일 관·층·분전함·차단기는 기존 데이터와 구간을 유지한다. 기존 이력도 보존한다. 없는 마스터만 추가하며 중간 실패 시 전체를 취소한다. 적용 완료 후 사용자가 수정·삭제한 마스터를 재실행·업데이트로 덮어쓰거나 복원하지 않는다. 원본을 다시 변환하는 것만으로 이미 적용된 DB가 갱신되지는 않는다.

로컬 테스트는 적재 수량, 단위·관 변환, SPARE 제외·기존 미사용 항목 정리, 미입력 보존, 트립 0건, 기존 데이터 보존, 삭제·수정 후 재실행, 실패 시 롤백·재시도, v2 업그레이드를 검증한다. 기기 테스트는 동봉 자료의 적재와 재실행 후 사용자 수정 보존을 검증한다.

## 0.7.0 SPARE 정리

`excel-masters-remove-spares-v1` 완료 기록으로 한 번만 정리한다. 원본 행 토큰으로 적재한 SPARE 중 모든 마스터 값·최초 설치일이 원본과 같고, 구간이 하나이며 트립이 없는 차단기만 삭제한다. 사용자 수정·신규 등록·추가 구간·트립 이력은 보존한다. 초기 적용 기록을 지우거나 DB를 초기화하지 않는다.
