# 검색·입력·정렬 설계

상태: 사용자 확정 완료. 검색·필수값·정렬·결과 표시 규칙을 [requirements.md](requirements.md)에 반영했다. 이 문서는 상세 동작과 예시·검증 시나리오를 설명하며, 앱 구현 완료를 의미하지 않는다.

## 1. 검색 조건

수정·삭제 대상 검색과 상세 조회는 같은 검색 규칙을 사용한다.

| 조건 | 상세 조회·수정·삭제 | 횟수 조회 | 기본값 / 일치 방식 |
| --- | --- | --- | --- |
| 관 | 사용 | 사용 | 전체 또는 1~4 선택, 선택값 정확히 일치 |
| 층 | 사용 | 사용 | 전체 또는 B1~B5·1~11·PH 선택, 선택값 정확히 일치 |
| 분전함번호 | 사용 | 사용 | 빈 값은 제한 없음, 입력하면 대소문자 구분 없이 포함 검색 |
| 차단기명 | 사용 | 사용 | 빈 값은 제한 없음, 입력하면 대소문자 구분 없이 포함 검색 |
| 트립일자 | 사용 | 사용하지 않음 | 기본 전체 날짜, 캘린더로 날짜 하나 선택 시 해당 날짜와 정확히 일치 |
| 교체 구간 범위 | 전체 구간의 이력 조회 | 현재 / 이전 / 전체 선택 | 횟수 조회는 현재 구간 기본값 |

입력한 조건은 모두 만족해야 한다(AND). 조건을 전부 비우면 상세 조회는 전체 트립 이력을, 횟수 조회는 선택한 구간 범위의 모든 구간을 조회한다. 첫 진입에도 기본 조건으로 결과를 표시한다.

트립 등록의 오늘 기본값과 검색의 전체 날짜 기본값은 구분한다. 검색에 오늘 날짜를 자동 적용해 과거 이력이 숨겨지지 않도록 한다.

| 동작 | 처리 |
| --- | --- |
| 조회 버튼 | 입력 중인 조건을 적용하여 결과 갱신 |
| 초기화 버튼 | 조건을 기본값으로 되돌리고 조회. 횟수 조회의 구간 범위도 현재로 복원 |
| 결과 없음 | ‘조건에 맞는 이력이 없습니다.’와 조건 초기화 동작 표시 |
| 검색 후 상세·수정 진입 | 돌아오면 적용했던 조건 유지, 저장 결과 반영 |
| 다른 조건으로 다시 조회 | 기존 삭제 대상 선택 해제 |

부분 검색 예: 분전함번호 `lp-3`은 `LP-3-A`, `LP-3-B`를 찾는다. 차단기명 `R1`은 `R1`, `R10`에도 일치하므로 결과에 전체 차단기명을 표시한다. `%`, `_`는 일반 입력 문자로 검색하며 사용자가 와일드카드 문법을 알 필요가 없게 한다.

검색의 부분 일치와 등록 시 동일 차단기 판단을 구분한다. 차단기 식별에는 정규화한 관·층·분전함번호·차단기명의 정확한 일치를 사용한다.

## 2. 등록·수정 필수값

| 항목 | 필수 여부 | 입력 처리 |
| --- | --- | --- |
| 관 | 필수 | 1~4 선택 |
| 층 | 필수 | 정해진 층 중 선택 |
| 분전함번호 | 필수 | 앞뒤 공백 제거, 영문 대문자 처리 |
| 차단기명 | 필수 | 앞뒤 공백 제거, 영문 대문자 처리 |
| 장소 | 필수 | 앞뒤 공백 제거, 영문 대문자 처리, 한글 유지 |
| 트립일자 | 필수 | 오늘 기본값, 확정된 날짜 범위 검증 적용 |
| 교체 구간 | 기존 차단기는 필수 | 현재 기본 선택, 필요시 이전 구간 선택 |
| 최초 교체일자 | 날짜 입력 또는 미상 선택 필수 | ‘교체일 미상’은 정상적인 선택값이며 날짜 누락 오류와 구분 |
| 비고 | 선택 | 빈 값 허용, 문장·줄바꿈·대소문자 유지 |

공백만 입력한 필수 문자열은 빈 값으로 처리한다. 식별값 내부의 공백·하이픈은 임의로 제거하거나 바꾸지 않는다. 예를 들어 ` lp-3-a `는 `LP-3-A`로 저장하지만 `LP-3 A`를 `LP-3-A`로 바꾸지는 않는다. 한글 입력 중 조합이 깨지지 않도록 처리하고 저장 시에도 같은 정규화를 적용한다.

필수값이 없으면 항목별 오류를 표시하고 첫 오류 위치로 이동한다. 횟수는 직접 입력받지 않고 실제 트립 이력에서 계산한다. 등록의 필수값을 검색 조건의 필수값으로 적용하지 않는다.

## 3. 기본 정렬

| 화면 | 기본 정렬 | 같은 값일 때 |
| --- | --- | --- |
| 상세 이력·수정·삭제 목록 | 트립일자 최신순 | 등록시각 최신순 → 고유 이력 ID로 고정 순서 |
| 횟수 조회 | 트립횟수 많은 순 | 관 오름차순 → 층 순서 → 분전함번호·차단기명 문자순 → 구간 순서 최신순 → 구간 ID |
| 차단기별 구간 선택 | 현재 구간 먼저, 이전 구간은 교체 순서 최신순 | 같은 날 교체도 구간 번호로 구분 |

층 순서는 B5 → B4 → B3 → B2 → B1 → 1 → … → 11 → PH로 둔다. 문자순 정렬은 같은 번호 체계에서 예측 가능하게 적용하되, R2와 R10을 숫자 크기로 비교하는 자연 정렬은 초기 요구에 포함하지 않는다.

미상 교체일은 현재 여부나 구간 순서를 결정하는 기준으로 사용하지 않는다. 0회 구간도 결과에 포함하고 횟수순 정렬의 아래쪽에 표시한다. 현재 구간만 보는 기본 화면에서는 과거 구간의 높은 횟수가 현재 상태와 섞이지 않는다.

## 4. 조회 결과 표시

| 화면 | 표시 |
| --- | --- |
| 상세 목록 | 차단기 식별 정보, 장소, 트립일자, 교체일자 또는 미상, 이력번호 |
| 상세 화면 | 원문 8개 항목 전체와 이력번호·등록시각 |
| 횟수 목록 | 관·층·분전함번호·차단기명·장소·교체일자 또는 미상·트립횟수·현재/이전 구분 |

원문 예시 표와 맞춰 횟수 조회에도 장소를 표시한다. 구간 안에서 장소가 다르면 **트립일자가 가장 최근인 이력의 장소**를 표시하고, 같은 날짜면 등록시각·이력 ID 순으로 결정한다. 트립이 없는 0회 구간의 장소는 ‘—’로 표시한다. 과거 구간에 입력된 장소를 현재 구간의 장소처럼 복사하지 않는다.

같은 날 동일한 값으로 등록한 두 이력은 `이력 #101`, `이력 #102`처럼 고유 번호로 구분한다. 등록시각은 입력한 시각이며 실제 트립 발생시각으로 표시하지 않는다. 번호는 삭제·정렬 후에도 바꾸지 않으며, 번호만으로 실제 발생 순서를 추정하지 않는다. 실제 상황을 구분할 정보가 필요하면 비고를 활용한다.

조회 결과 행 수와 트립횟수도 구분한다. 상세 화면의 ‘이력 12건’은 트립 행 수이고, 횟수 화면의 ‘구간 5개’는 집계 행 수다.

아래는 확정 정책에 대한 테스트 계획이며, 실행 가능한 테스트는 아직 작성하지 않았다.

| ID | 시나리오 | 기대 결과 |

| SEARCH-01 | 상세 검색 조건을 모두 비움 | 날짜·구간에 관계없이 모든 트립 이력 조회 |
| SEARCH-02 | 관 1·층 3·분전함 lp-3 입력 | 세 조건을 모두 만족하는 결과만 표시 |
| SEARCH-03 | 차단기명 R1 검색 | R1·R10 포함, 결과에 전체 이름 표시 |
| SEARCH-04 | 트립 날짜 하나 선택 | 해당 날짜의 실제 다회 트립을 모두 반환 |
| SEARCH-05 | 조회 조건 변경 후 다시 검색 | 삭제 선택 해제, 새 결과에 이전 선택이 적용되지 않음 |
| SEARCH-06 | 문자 %, _ 입력 | 와일드카드가 아닌 문자 자체로 검색 |

| INPUT-02 | 식별값 소문자·앞뒤 공백, 한글 장소 입력 | 영문 대문자·공백 제거, 한글 유지, 내부 하이픈 보존 |
| INPUT-03 | 최초 교체일 미상 선택, 비고 빈 값 | 다른 필수값이 유효하면 저장 가능 |
| SORT-01 | 날짜가 같은 트립 두 건 | 등록시각 및 ID 기준으로 안정된 순서, 각각 선택 가능 |
| SORT-02 | 현재 구간 0·2·5회 | 5 → 2 → 0회, 과거 구간은 기본 화면에 없음 |
| SORT-03 | 동률 횟수와 지하·지상층 | 관·층·식별값 기준으로 정렬, 재조회 시 동일 순서 |
| DISPLAY-01 | 한 구간의 장소가 이력마다 다름 | 최신 트립 기준 장소 표시, 원본 상세 장소는 각각 유지 |
| DISPLAY-02 | 0회·교체일 미상 구간 | 조회에서 누락되지 않으며 장소 ‘—’, 교체일 미상 표시 |

## 6. 확정 요약

검색 조건은 선택 입력·AND 조합, 코드 필드는 포함 검색, 날짜는 하루 단위 정확한 일치로 적용한다. 등록은 비고만 선택이며 교체일은 미상으로 대체할 수 있다. 상세 이력은 최신순, 횟수는 현재 구간을 기본으로 많은 순서로 보여준다. 횟수 조회의 장소와 같은 날 이력을 구분할 고유 번호도 표시한다.
