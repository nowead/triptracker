# Trip Tracker 화면 디자인

사용자가 승인한 분전함 중심 메인 화면과 미니멀 디자인을 0.4.0에 적용했다. 업무 규칙은 [요구사항](requirements.md)을 따른다.

| 요소 | 적용 |
| --- | --- |
| 이름 | 런처·상단에 Trip Tracker |
| 서체 | 시스템 SansSerif. 기기의 한글 글꼴을 사용하며 별도 다운로드 없이 동작 |
| 정보 위계 | 합계 48sp, 화면 제목 24sp, 카드 제목 16sp, 본문 14sp, 보조 정보 12sp. 시스템 글자 배율 적용 |
| 색상 | 배경 #F6F7FA, 카드 흰색, 본문 #182333, 보조 #596779, 강조 #315AD8 |
| 카드 | 얇은 경계선, 둥근 모서리, 18~22dp 안쪽 여백. 총 횟수 카드만 짙은 남색 |
| 아이콘 | Compose로 그린 선형 아이콘. 버튼에 텍스트 제공, 체크박스에 이력별 접근성 설명 |
| 시스템 바 | 밝은 화면에 어울리는 어두운 상태·내비게이션 아이콘 |

| 화면 | 사용 흐름 |
| --- | --- |
| 현황 | 전체/관 선택 → 현재 구간 합계 → 관·층별 분전함. 분전함을 누르면 차단기별 현재 횟수 펼치기/접기 |
| 차단기 이력 | 정확히 일치하는 차단기의 전체 교체 구간 이력. 조회 범위와 ‘분전함 현황으로’ 표시 |
| 상세·횟수 조회 | 목록 우선 표시. ‘검색’으로 조건을 펼치며 적용 조건은 목록 위에 표시 |
| 선택 삭제 | ‘선택’으로 체크박스 표시 → 하나/여러 건 선택 → 삭제 확인. ‘선택 취소’로 일반 목록 복귀 |
| 등록·수정 | 같은 입력 컴포넌트와 52dp 이상 선택 버튼, 54dp 이상 저장 버튼 사용 |

현황은 별도의 Room Flow를 관찰하여 검색 조건과 관계없이 저장·수정·삭제 결과를 반영한다. 메인과 차단기별 횟수는 현재 구간이며, 차단기 이력은 과거 구간도 포함한다고 명시한다. 자동 경고 임계값이나 교체 권고는 도입하지 않았다.

실제 폰에서 큰 글자, 좁은 화면, 키보드, 시스템 뒤로 가기, 업데이트 설치 후 기존 데이터 보존을 추가 확인한다. 로컬 테스트와 실제 기기 검증 상태는 [검증 계획](test-plan.md)에 기록한다.

`RegistrationScreenTest`의 현황 시나리오는 Robolectric 네이티브 렌더링으로 `app/build/reports/ui/home.png`를 생성한다. 테스트용 이력으로 만든 화면 캡처이며 실제 기기 캡처와 구분한다.
