# Trip Tracker 화면 디자인

0.5.0은 [요구사항](requirements.md)의 2026-09-27 마스터 중심 화면 개편과 시인성·여백 개선을 적용한다.

| 현재 디자인 기준 | 적용 |
| --- | --- |
| 색상 | 본문 #14263D, 보조 #526477, 강조 #006C67, 배경 #F2F5F9, 카드 흰색 |
| 여백 | 화면·카드 안쪽 20dp, 입력 간격 16dp, 카드 정보 간격 8~12dp |
| 글꼴 | 시스템 한글 SansSerif 유지. 본문 15sp / 행간 24sp, 입력 16sp / 26sp, 화면 제목 25sp / 34sp |
| 검색 | 흰색 독립 카드, ‘조회 조건’ 제목, 충분한 대비의 입력 테두리, 48dp 이상 조회 버튼 |
| 결과 | 제목·소속·항목 이름·값의 위계 분리. 차단기 사양은 줄바꿈 가능한 배지로 표시 |
| 빈 목록 | 아이콘·제목·안내를 묶은 카드. 긴 문장을 한 줄에 몰아넣지 않음 |
| 내비게이션 | 현재 탭은 청록색 표시와 배경. 차단기·위치 전용 아이콘, 큰 글자에서 두 줄 라벨 허용 |
| 입력·상세 | 동일한 모서리와 간격, 입력 선택 표시, 항목 이름과 값의 정렬, 삭제 동작은 붉은색 |

큰 글자(1.3배)와 360dp 화면에서 등록 버튼·필수값 오류·선택창·스크롤·메뉴 이동을 Compose 테스트로 검증한다. 기능 회귀 테스트와 에뮬레이터 화면 확인을 함께 수행한다.

| 현재 화면 | 사용 흐름 |
| --- | --- |
| 분전함 마스터 (시작) | 관·층·번호 검색, 위치·특기사항 조회, 등록·수정·삭제 |
| 차단기 마스터 | 소속 분전함 선택, 종류·port·A·설치일·부하·특기사항 입력. 설치 구간 메뉴에서 교체·날짜 정정·빈 구간 삭제 |
| 트립이력 | 기존 차단기·설치 구간 선택 → 트립일자·장소·사유·특기사항 저장. 목록 상세·수정 및 선택 삭제 |
| 건수조회 | 관·층 필수, 분전함·차단기번호 선택, 현재/이전/전체 구간. 행을 눌러 헤더로 이동 → 헤더를 눌러 해당 구간 이력 팝업 |
| 위치조회 | 장소(부하) 부분 검색 → 관·층·분전함번호·분전함위치·차단기번호·부하 |
| 반복 입력 | 저장 이력이 있는 필드에 ‘목록’ 표시 → 목록 내 검색·선택. 직접 새 값 입력 가능 |

필수값 오류를 필드 아래에 표시하고 첫 오류로 스크롤한다. 저장 중 중복 입력과 화면 이동을 제한하고 실패 시 입력을 보존한다. 각 메뉴의 적용 검색 조건은 수정·상세 복귀 후 유지한다.

아래 현황 중심 흐름은 0.4.0의 참고 기록이다.

| 요소 | 적용 |
| --- | --- |
| 이름 | 런처·상단에 Trip Tracker |
| 서체 | 시스템 SansSerif. 기기의 한글 글꼴을 사용하며 별도 다운로드 없이 동작 |
| 정보 위계 | 합계 48sp, 화면 제목 24sp, 카드 제목 16sp, 본문 14sp, 보조 정보 12sp. 시스템 글자 배율 적용 |
| 색상 | 배경 #F6F7FA, 카드 흰색, 본문 #182333, 보조 #596779, 강조 #315AD8 |
| 카드 | 얇은 경계선, 둥근 모서리, 18~22dp 안쪽 여백. 총 횟수 카드만 짙은 남색 |
| 아이콘 | Compose로 그린 선형 아이콘. 버튼에 텍스트 제공, 체크박스에 이력별 접근성 설명 |
| 시스템 바 | 밝은 화면에 어울리는 어두운 상태·내비게이션 아이콘 |

| 화면 | 사용 흐름 |
| --- | --- |
| 현황 | 전체/관 선택 → 현재 구간 합계 → 관·층별 분전함. 분전함을 누르면 차단기별 현재 횟수 펼치기/접기 |
| 차단기 이력 | 정확히 일치하는 차단기의 전체 교체 구간 이력. 조회 범위와 ‘분전함 현황으로’ 표시 |
| 상세·횟수 조회 | 목록 우선 표시. ‘검색’으로 조건을 펼치며 적용 조건은 목록 위에 표시 |
| 선택 삭제 | ‘선택’으로 체크박스 표시 → 하나/여러 건 선택 → 삭제 확인. ‘선택 취소’로 일반 목록 복귀 |
| 등록·수정 | 같은 입력 컴포넌트와 52dp 이상 선택 버튼, 54dp 이상 저장 버튼 사용 |

현황은 별도의 Room Flow를 관찰하여 검색 조건과 관계없이 저장·수정·삭제 결과를 반영한다. 메인과 차단기별 횟수는 현재 구간이며, 차단기 이력은 과거 구간도 포함한다고 명시한다. 자동 경고 임계값이나 교체 권고는 도입하지 않았다.

실제 폰에서 큰 글자, 좁은 화면, 키보드, 시스템 뒤로 가기, 업데이트 설치 후 기존 데이터 보존을 추가 확인한다. 로컬 테스트와 실제 기기 검증 상태는 [검증 계획](test-plan.md)에 기록한다.

`RegistrationScreenTest`의 현황 시나리오는 Robolectric 네이티브 렌더링으로 `app/build/reports/ui/home.png`를 생성한다. 테스트용 이력으로 만든 화면 캡처이며 실제 기기 캡처와 구분한다.

## 0.7.0 마스터 목록

분전함·차단기는 안쪽 가로 14dp·세로 10dp, 행 간 8dp의 콤팩트 카드로 표시한다. 번호·소속·위치/부하·주요 사양을 우선하고 특기사항은 한 줄 요약한다. 전체 정보는 48dp 점 세 개 메뉴의 상세 보기로 확인한다. 수정·삭제·설치 구간도 이 메뉴에 두고 삭제는 별도 확인한다. 검색·필터는 접어서 목록 공간을 확보하고, 적용된 조건은 접힌 상태에도 표시한다. 큰 글자에서는 제목·사양을 줄바꿈한다.

## 0.8.0 부모 분전함 선택과 검색

분전함 행을 누르거나 점 세 개 메뉴의 ‘차단기 추가’를 누르면 해당 부모를 미리 지정한 차단기 등록 화면을 연다. 관·층·분전함 선택을 위쪽에 두고, 상위 값을 바꾸면 하위 선택을 해제한다. 등록·수정의 분전함 목록은 해당 관·층에 속한 항목만 표시한다.

모든 검색 화면은 조회 후 필터를 접고 결과 위에 적용 조건을 표시한다. 검색·필터 버튼으로 다시 연다. 분전함 선택 창은 관·층으로 범위를 제한하며 번호로 목록을 검색하거나 입력값을 부분 검색 조건으로 적용할 수 있다. 선택은 고유 분전함 ID를 사용한다.

차단기 행에서 적용된 관·층을 반복하지 않는다. 특정 분전함까지 선택했으면 소속 줄 전체를 생략한다. 입력 중인 조건은 결과 요약에 영향을 주지 않는다. 상세 보기와 메뉴 접근성 설명에는 전체 소속을 유지한다. 큰 글자에서도 상단 동작 버튼이 줄바꿈되도록 배치한다.
